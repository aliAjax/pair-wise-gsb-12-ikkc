# 地铁夜间检修派车台

- 场景：地铁夜间检修派车，替代纸面沟通，发车前自动核对冲突
- 技术栈：Vue3、Vite、TypeScript
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 功能

- **作业登记**：行车区间、封锁时段（跨零点按次日凌晨计）、车型、驻车点
- **轨道车登记**：可用时段、剩余电量、电耗（%/km）、驻车点
- **派车核对**（`src/domain.ts` 纯函数引擎）：
  - 同区间占用：时段重叠即报冲突区间
  - 相邻区间串车：开往作业区间需穿越已占用区间即拦截，给出串车距离
  - 往返耗电：往返里程 × 电耗 + 10% 安全余量，不足报缺多少电
  - 另核对车型匹配、车辆可用时段、车辆重复占用
- **待派区**：核对不过的作业留在待派区，写明冲突区间 / 串车距离 / 缺电量
- **锁定与释放**：确认派车后锁住关系；撤单、改点、重开释放占用，重开后保留待派原因可继续跟进

数据保存在浏览器 localStorage（键：`metro-night-dispatch-v1`），清除后恢复示例数据。
