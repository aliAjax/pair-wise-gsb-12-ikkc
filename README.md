# 地铁夜间检修派车台

- 行业：轨道交通（地铁夜间检修）
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

车辆页已补成检修派车台，数据默认保存在浏览器 localStorage 中：

- 每项作业登记行车区间、封锁时段、需求车型、驻车点与作业点里程
- 轨道车登记可用时段、剩余电量与耗电率
- 派车核对同区间占用、相邻区间串车（安全间距 1.0 km）与往返耗电（保底 20% 电量）
- 不足项把作业留在待派区，写清冲突区间、串车距离或缺多少电
- 撤单、改点、重开立即释放车辆与区间占用；确认派车后锁定关系并预扣电量，全程留痕可追
